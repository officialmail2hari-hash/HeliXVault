HELIXVAULT

HOME PAGE:
- Shows only the supplied DNA image (dna.png), HeliXVault logo and upload button.

AFTER UPLOAD:
- Automatically opens storage.html.
- storage.html uses the supplied DNA video (dna.mp4) as the main visual.
- Uploaded file information, floating binary, DNA sequence and progress animation appear over the video.

Run:
1. Extract this folder.
2. Open index.html in Chrome/Edge.
3. Click Upload File and select a file.
